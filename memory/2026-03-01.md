### 技术细节

**inlineHighlightStyles() 函数**：
```typescript
function inlineHighlightStyles(html: string): string {
  const styles: Record<string, string> = {
    'hljs-comment': 'color: #6a737d; font-style: italic;',
    'hljs-keyword': 'color: #d73a49; font-weight: bold;',
    'hljs-string': 'color: #032f62;',
    // ... 所有语法高亮样式
  }
  
  for (const [className, style] of Object.entries(styles)) {
    const regex = new RegExp(`class="${className}"`, 'g')
    html = html.replace(regex, `class="${className}" style="${style}"`)
  }
  
  return html
}
```

## 🔧 列表格式修复 - 2026-03-01 11:25 UTC

### 用户反馈
> "序列错乱的问题，原文是无序列表，但在微信中变成了有序列表 1, 2, 3... 而且第一项是空的"

### 问题根因
1. CSS `list-style-type: disc` 在微信公众号中不被支持
2. 微信会错误渲染或忽略列表样式
3. 结果：无序列表显示为有序列表，或完全不显示符号

### 解决方案

**手动为每个 `<li>` 添加前缀符号**：

```typescript
// 处理有序列表
html = html.replace(/<ol[^>]*>([\s\S]*?)<\/ol>/g, (match, content) => {
  let counter = 0
  const processed = content.replace(/<li>/g, () => {
    counter++
    return `<li style="${styles.li}"><span style="margin-right: 8px; font-weight: bold;">${counter}.</span>`
  })
  return `<ol style="${styles.ol}">${processed}</ol>`
})

// 处理无序列表
html = html.replace(/<ul[^>]*>([\s\S]*?)<\/ul>/g, (match, content) => {
  const processed = content.replace(/<li>/g, () => {
    return `<li style="${styles.li}"><span style="margin-right: 8px;">•</span>`
  })
  return `<ul style="${styles.ul}">${processed}</ul>`
})
```

**输出示例**：
```html
<!-- 无序列表 -->
<ul style="list-style-type: none;">
  <li><span style="margin-right: 8px;">•</span>列表项 1</li>
  <li><span style="margin-right: 8px;">•</span>列表项 2</li>
</ul>

<!-- 有序列表 -->
<ol style="list-style-type: none;">
  <li><span style="margin-right: 8px; font-weight: bold;">1.</span>第一项</li>
  <li><span style="margin-right: 8px; font-weight: bold;">2.</span>第二项</li>
</ol>
```

### 更新文件
- `wechat-formatter-fixed.ts` - 添加列表前缀处理
- `FORMAT_SPEC.md` - 添加列表格式规范
- `SKILL.md` - 强调列表处理要求

### 新草稿 ID
`tdXp0No2A1pitGguS6BlZ0hT4GLpsuKOm0cBLVcwmVe48RdFbOx8Z9hctmsFudFV`

### 技术要点
1. **禁用原生列表样式**：`list-style-type: none`
2. **手动添加前缀**：
   - 无序列表：`•` （Unicode 圆点）
